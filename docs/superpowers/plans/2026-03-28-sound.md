# Sound (Howler.js) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add game sound effects using Howler.js (already installed). All sounds are triggered in response to game actions. A mute toggle persists to localStorage.

**Architecture:** A singleton `soundService` (analogous to `socketService`) holds all Howler instances. Sound is triggered by listening to store state changes in a `useSoundEffects` hook that lives in `GameScreen`. No store changes needed beyond adding `muted: boolean` to the store.

**Howler.js version:** 2.2.4 (already installed). Key API: `new Howl({ src: [...] })`, `.play()`, `.mute(true)`.

**Sound files:** Generate or obtain short free-license audio files and place them in `public/sounds/`. For initial implementation, use free CC0 sounds. The plan below uses placeholder paths — replace with actual files before deploying.

```ts
import { Howl } from 'howler'

const sounds = {
  take:      new Howl({ src: ['/sounds/take.mp3'],      volume: 0.6 }),
  camels:    new Howl({ src: ['/sounds/camels.mp3'],    volume: 0.7 }),
  sellSmall: new Howl({ src: ['/sounds/sell-small.mp3'], volume: 0.6 }),
  sellBig:   new Howl({ src: ['/sounds/sell-big.mp3'],  volume: 0.8 }),
  bonus:     new Howl({ src: ['/sounds/bonus.mp3'],     volume: 0.9 }),
  roundEnd:  new Howl({ src: ['/sounds/round-end.mp3'], volume: 0.8 }),
} as const

type SoundName = keyof typeof sounds

let _muted = localStorage.getItem('vjaipur-muted') === 'true'

export const soundService = {
  play(name: SoundName) {
    if (!_muted) sounds[name].play()
  },
  setMuted(muted: boolean) {
    _muted = muted
    localStorage.setItem('vjaipur-muted', String(muted))
  },
  get muted() { return _muted },
}
```

## Task 3: useSoundEffects hook

- [ ] **Step 3.1** Create `src/hooks/useSoundEffects.ts`:

```ts
import { useEffect, useRef } from 'react'
import { useGameStore } from '../store/gameStore'
import { soundService } from '../audio/soundService'

export function useSoundEffects() {
  const state = useGameStore(s => s.state)
  const lastMoveDescription = useGameStore(s => s.lastMoveDescription)
  const prevDescRef = useRef<string | null>(null)
  const prevBonusCountRef = useRef<number>(0)
  const myIndex = useGameStore(s =>
    s.mode === 'vs-ai' ? 0 :
    s.mode === 'online' ? (s.onlinePlayerIndex ?? 0) :
    s.state?.activePlayer ?? 0
  )

  // Trigger sound when lastMoveDescription changes (opponent/AI just moved)
  useEffect(() => {
    if (!lastMoveDescription || lastMoveDescription === prevDescRef.current) return
    prevDescRef.current = lastMoveDescription

    if (lastMoveDescription.startsWith('took') && lastMoveDescription.includes('camel')) {
      soundService.play('camels')
    } else if (lastMoveDescription.startsWith('sold')) {
      const qty = parseInt(lastMoveDescription.split(' ')[1])
      soundService.play(qty >= 3 ? 'sellBig' : 'sellSmall')
    } else if (lastMoveDescription.startsWith('took') || lastMoveDescription.startsWith('made')) {
      soundService.play('take')
    }
  }, [lastMoveDescription])

  // Trigger bonus sound when player earns a bonus token
  useEffect(() => {
    if (!state) return
    const bonusCount = state.players[myIndex].bonusTokens.length
    if (bonusCount > prevBonusCountRef.current) {
      soundService.play('bonus')
    }
    prevBonusCountRef.current = bonusCount
  }, [state, myIndex])

  // Trigger round-end sound
  useEffect(() => {
    if (state?.phase === 'round-end') {
      soundService.play('roundEnd')
    }
  }, [state?.phase])
}
```
