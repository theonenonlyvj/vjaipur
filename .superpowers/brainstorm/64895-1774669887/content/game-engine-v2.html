Game Engine Design

Pure TypeScript module — the single source of truth for all game logic

State Shape
// Everything the game needs — nothing more
type GameState = {
phase: 'setup' | 'playing' | 'round-end' | 'game-over'
round: number // 1–3 max
activePlayer: 0 | 1
market: Card[] // always 5 cards
deck: Card[] // face-down
players: [PlayerState, PlayerState]
tokens: TokenPiles // remaining on board
bonusTokens: BonusPiles // 3/4/5+ stacks
seals: [number, number] // seals earned per player
}
type PlayerState = {
hand: Card[] // ≤7 goods at turn end
herd: number // camel count (hidden from opp)
tokens: Token[] // earned this round
}
Actions — the only way state changes
TAKE_SINGLE
Take 1 goods card from market by index. Auto-refills from deck. Validated on resulting state: hand must be ≤7 at turn end.
TAKE_EXCHANGE
Take ≥2 goods from market, return same count from hand. Hand may transiently exceed 7 during resolution — only the final hand size is checked (≤7). Validates: no same-type swap, min 2 cards.
TAKE_CAMELS
Take all camels from market into herd. Camels never count toward hand limit. Refills every taken slot from deck. Fails if no camels in market.
SELL
Sell ≥1 card of one goods type (≥2 for diamond/gold/silver). Awards goods tokens + bonus token if 3+ cards sold. Checks round-end condition after resolving.
Hand limit rule — enforced here only
Every action runs its full resolution first (cards move, deck refills, camels go to herd), then a single post-resolution check confirms player.hand.length ≤ 7. No intermediate state is ever rejected for hand size.
